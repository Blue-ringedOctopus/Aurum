【项目名称】Aurum - 中医病历智能整理工具
【当前状态】已发布 v1.0.0（Windows + macOS），约35人测试。根据测试反馈，已修复若干bug，并调整了自动更新方案。当前正在准备 v1.0.1 或 v1.0.2 的发布，主要包含bug修复和UI优化。

【项目定位】
帮助中医学生/临床医生整理散落在各日期文件夹中的患者病历资料，自动重组为“医院/患者/就诊日期”结构，存入SQLite本地数据库，支持搜索、筛选、分组、批量编辑、删除，并提供AI辅助功能（中医证型识别、方剂识别、按语生成）。

【技术栈】
Python 3.11
Streamlit（Web界面框架）
SQLite（本地数据库）
PyInstaller（Windows打包，onedir模式）
GitHub Actions（用于自动构建macOS版本，但需谨慎配置依赖）
DeepSeek API（AI推理，需用户自备API Key）

【核心模块及文件路径（相对于项目根目录）】
aurum_app.py：主入口，含登录/注册/路由/版本检查/侧边栏设置
aurum_core/tab1.py：归档整理界面（源目录→目标目录复制，以及刷新数据库）
aurum_core/tab2.py：智能体界面（诊断识别、方剂识别、按语生成）
aurum_core/tab3.py：数据库浏览界面（表格展示、筛选、排序、批量编辑、删除记录）
aurum_core/file_processor.py：核心归档逻辑（文件复制、索引写入、刷新索引、患者档案生成）
aurum_core/database.py：数据库初始化、升级、查询接口、load_all_visits_with_tags
aurum_core/deidentifier.py：脱敏模块（本地替换姓名/身份证/电话等，仅脱敏后的医学文本发送云端）
aurum_core/text_utils.py：文本读取、处方提取、诊断解析、敏感信息检测、日期标准化
aurum_core/llm_agent.py + llm_tools.py：DeepSeek API调用封装，含诊断、方剂、按语生成
aurum_core/extract_patient_profiles.py：从初诊病历自动提取患者档案信息（性别/出生日期/电话等），独立脚本，可单独运行
aurum_core/ui_components.py：通用UI组件（患者选择器、就诊日期选择器、文件夹打开、编辑记录、批量标签编辑）
aurum_core/delete_handler.py：删除记录及关联文件夹（含同步删除选项）
aurum_core/utils.py：跨平台打开文件夹函数
run.py：PyInstaller入口文件（位于根目录，用于打包）

【关键设计决策（务必继承）】
数据流向：文件层（原始散落文件夹）-> 复制重组（归档层）-> SQLite索引层 -> AI推理层。
脱敏策略：所有发送至DeepSeek API的文本必须先经过本地脱敏（替换姓名/身份证/电话/标签字段），仅保留医学描述。
诊断提取：使用正则跨行匹配，遇到下一个字段标签（如“方药：”“舌脉：”“备注：”等）自动截断，避免误读。
标签系统：患者级分组（patient_group_tags）和就诊级标记（visit_mark_tags）并存，均支持多选、交集/并集筛选。
编辑功能：编辑就诊记录仅限诊断、方剂、备注，不涉及标记（标记通过批量编辑功能操作）。
UI交互原则：完全听从用户（即开发者）的实际使用习惯，不强行预设。

【自动更新策略】（已定稿）
经测试，一键自动更新（下载替换exe）在打包环境中存在SSL证书验证和进程替换等问题，难以稳定实现。故最终决定放弃一键更新，改为：
  程序启动或点击“检查更新”时，访问GitHub API获取最新Release版本号。
  若有新版本，显示提示信息，并提供 st.markdown 超链接直接跳转到GitHub Releases页面，让用户手动下载替换。
  保留“本次忽略”按钮（可暂时忽略某版本）。
该方案已在 v1.0.0 中实现，未收到用户反馈。打包时不再需要包含 updater.exe，也无需处理SSL证书（使用 verify=False 已足够）。

【macOS 打包与分发】
macOS 版本通过 GitHub Actions 自动构建（工作流文件 .github/workflows/build.yml）。
构建时需注意：requirements.txt 中不能包含 pywin32，因为 macOS 无法安装。需将 pywin32 单独在 Windows 构建步骤中安装。
macOS 用户首次打开需右键 -> 打开，或通过终端执行 sudo xattr -d com.apple.quarantine /path/to/Aurum.app 移除隔离属性。
当前 macOS 版本已成功构建并分发，用户反馈不可打开（因为开发者证书原因）。
目前打算放弃mac版本

【打包与发布须知】
使用 PyInstaller 的 onedir 模式（不是 onefile），因为启动更快，便于后续更新替换部分文件。
打包命令（示例）：
  pyinstaller --onedir --noconsole --icon=Aurum.ico --name Aurum --add-data "aurum_core;aurum_core" --add-data "README.txt;." --add-data "aurum_app.py;." --hidden-import streamlit ... --collect-all streamlit --collect-all certifi run.py
具体参数参见项目根目录下的 aurum.spec 文件（若有）。
打包前确保已删除 build/ 和 dist/ 目录，以免残留。
当前分发版本为 v1.0.0（Windows）和 v1.0.0（macOS 通过 GitHub Actions 构建）。
