                        📜 Aurum - 中医病历智能整理工具
                        v1.0.2

                            1. 这是什么工具？

跟诊后，文件夹通常是这样的：

  2025-06-01 曙光医院/
  ├── 张三/
  │   ├── 病历.docx
  │   └── 舌象.jpg
  ├── 李四/
  │   └── 病历.docx
  2025-06-15 曙光医院/
  ├── 张三/
  │   └── 病历.docx
  └── 王五/
      └── ...

想查张三的所有就诊记录，得在十几个日期文件夹里翻来翻去。

Aurum 帮你做三件事：
  1. 把上面的文件夹自动重组为“患者/就诊日期”的结构。
  2. 把所有病历信息存入数据库，支持搜索、筛选、分组。
  3. 用 AI 帮你识别证型、方剂名，自动生成按语。

                            2. 拿到软件后怎么用？

  1. 解压整个文件夹到你的电脑上（不要只把 Aurum.exe 拖出来，整个文件夹
     要在一起）。
  2. 双击 Aurum.exe，允许访问公共网络。
  3. 等待几秒钟，浏览器会自动打开，显示 http://localhost:8501。
  4. 看到登录页面，说明启动成功了。

注意：第一次启动会稍慢（10 秒左右），是正常的。后续启动会快一些。


                            3. 第一次使用做什么？

  ① 注册账号
     - 点击“注册新账号”，输入用户名和密码（密码至少 6 位）。
     - 注册成功后，用刚注册的账号登录。

  ② 填入你的 DeepSeek API 密钥（可选）
     - 登录后，在“🤖 智能体”标签页里，展开“🔑 账号 API 密钥管理”。
     - 输入你在 DeepSeek 平台申请的 API 密钥，点击保存。
     - 不填也能用归档和数据库浏览功能，只是 AI 识别功能用不了。

     【为什么要填 API 密钥？】
     AI 识别（证型、方剂、按语）需要调用 DeepSeek 的大模型，
     这是付费服务，需要你自己充值。本工具不收取任何额外费用。

  ③ 开始归档
     - 在“📂 归档整理”标签页，选择你的源目录（比如 D:/2025年病历）。
     - 选择或生成目标目录（默认会在源目录旁边自动生成一个
       “_Aurum归档” 文件夹）。
     - 点击“执行归档整理”，等待完成。


                            4. 两种模式的区别

  Aurum 提供了两种方式处理你的病历，根据情况选择：

  【归档整理】（主界面）
  - 适用场景：你手里的是**未整理**的日期文件夹
  - 会做什么：复制文件到目标目录，生成患者档案，建立数据库索引

  【刷新数据库】（折叠面板，在“归档整理”页面下方）
  - 适用场景：你已经有了**已整理好**的归档结构（患者/日期）
  - 会做什么：更新数据库中的文件路径和病历内容，同步更新患者档案
  - 相当于「路径更新 + 内容同步 + 索引重建」三合一


                            5. ⭐ v1.0.2 新功能详解

  【📦 移动模式】（侧边栏 → 高级设置 → 归档模式）
  - 复制模式（默认）：保留原始文件，安全可靠
  - 移动模式：归档后自动删除原始文件，节省硬盘空间
  - 建议仅在确认数据已完整归档后使用

  【🏥 启用医院/科室层】（侧边栏 → 高级设置）
  - 开启（默认）：归档结构为「目标目录/医院/患者/日期」
  - 关闭：归档结构为「目标目录/患者/日期」（适合只跟一家医院的用户）

  【💾 设置持久化】（侧边栏 → 高级设置 → 保存当前设置）
  - 修改任何设置后立即生效，无需重启
  - 点击「保存当前设置」永久固化到配置文件
  - 下次启动自动恢复你的偏好

  【✏️ 重命名患者】（数据库浏览 → 编辑就诊记录 → 个人信息）
  - 修正抓取错误的患者姓名
  - 同时更新数据库、就诊记录、标签和患者档案文件
  - ⚠️ 注意：不会自动重命名硬盘文件夹，需手动操作


                            6. 文件都放在哪里？

  内容                    存放位置
  --------------------------------------------------------------
  程序本身                你解压后的整个文件夹（所有文件要在一起）
  数据库                  aurum_index.db（和 Aurum.exe 在同一目录）
  配置文件                config.yaml（和 Aurum.exe 在同一目录）
  归档后的文件            你自己指定的“目标目录”
  临时文件                系统临时目录（自动清理，不用管）

  【重要】数据库（aurum_index.db）和配置文件（config.yaml）包含
  你所有的患者数据、就诊记录、诊断方剂、标签分组和登录账号信息。

  如果你要：
  - 备份数据：复制这两个文件到安全位置即可。
  - 迁移到新电脑：把整个 Aurum 文件夹复制过去，或只复制这两个
    文件到新安装的 Aurum 目录下。
  - 更新版本：这两个文件不会被覆盖（见下一节）。

  请务必不要把 aurum_index.db 和 config.yaml 删掉或弄丢，
  否则所有数据都会丢失。


                            7. 如何更新到新版本？

  Aurum 支持自动检查和手动更新两种方式，推荐使用自动检查。

  【方式一：自动检查更新】（Windows 推荐）
  1. 登录后，在左侧边栏点击“🔍 检查更新”。
  2. 如果有新版本，页面会显示提示和下载链接。
  3. 点击“前往下载”按钮，下载最新版本的压缩包。
  4. 下载完成后，解压压缩包。
  5. 关闭 Aurum 程序（关闭浏览器窗口和命令行窗口）。
  6. 将解压后的 Aurum.exe 和 aurum_core 文件夹（如果有更新）
     复制到旧版本的文件夹中，覆盖同名文件。
  7. 重新启动 Aurum，更新完成。

  【方式二：手动更新】（所有系统通用）
  1. 前往 GitHub Releases 页面下载最新版本的压缩包。
  2. 关闭 Aurum 程序。
  3. 解压下载的压缩包。
  4. 将旧版本文件夹\_internal中的aurum_index.db 和 config.yaml移动到解压后的新版本的\_internal中
     注意：**千万不要弄丢 aurum_index.db 和 config.yaml**，
     这两个文件包含了你的所有数据和账号信息。
  5. 重新启动 Aurum，更新完成。

  【重要提醒】
  - 数据库文件（aurum_index.db）和配置文件（config.yaml）
    必须保留，它们存储了你所有的患者数据、就诊记录和登录账号。
  - 如果你误覆盖了这两个文件，数据将丢失且无法恢复。

                            8. 我不想用了，怎么删？

  直接删除整个文件夹即可。Aurum 不会往系统盘写任何东西，不会留下垃圾文件。

  如果你想保留数据但卸载程序，把 aurum_index.db 和 config.yaml 复制到别处，
  然后删除其他文件即可。


                            9. 注意事项（重要！）

  ① 不要把 Aurum.exe 单独拖出来
     整个文件夹要在一起，否则程序会找不到数据库和配置文件。

  ② 移动整个文件夹时
     数据库和配置会跟着走，数据不丢。但不要只移动 exe，要移动整个文件夹。

  ③ API 密钥是付费的
     本工具调用 DeepSeek 的 API 是需要你自己充值的。建议先在 DeepSeek 官网
     充值少量金额试用。

  ④ 数据安全
     Aurum 不会把你的病历上传到任何云端。唯一发到网上的内容是你脱敏后发给
     DeepSeek API 的医学描述文本，且不包含任何个人身份信息。

  ⑤ 杀毒软件误报
     由于打包方式的特性，部分杀毒软件可能会误报。这是正常现象，请将 Aurum
     添加到信任列表。

  ⑥ 端口占用
     如果 8501 端口被占用，程序可能无法启动。可以关闭其他占用该端口的程序，
     或修改 run.py 中的端口号。


                            10. 常见问题

  Q：双击 Aurum.exe 没反应怎么办？
  A：打开任务管理器，看看有没有 Aurum.exe 或 python 进程在运行。如果有，
     可能是浏览器没自动打开，手动输入 http://localhost:8501 访问。

  Q：提示“无法找到 config.yaml”怎么办？
  A：检查一下 config.yaml 是否和 Aurum.exe 在同一个文件夹里。如果是第一次运行，
     可能还没生成，可以重新解压完整的文件夹。

  Q：换了电脑，数据怎么迁移？
  A：把整个 Aurum 文件夹复制到新电脑即可。如果只想迁移数据，复制
     aurum_index.db 和 config.yaml 到新电脑的 Aurum 目录下。

  Q：忘记密码怎么办？
  A：在登录页面点击“忘记密码”，输入用户名并重置密码。

  Q：归档后的文件在哪里？
  A：你在“归档整理”页面指定的“目标目录”就是归档后的位置。如果你没有手动改，
     默认会在源目录旁边生成一个“_Aurum归档”文件夹。

  Q：AI 识别提示“API 密钥未保存”怎么办？
  A：在“智能体”页面展开“API 密钥管理”，填入你的 DeepSeek API 密钥并保存。

  Q：重命名患者后，硬盘上的文件夹没有改名怎么办？
  A：这是正常的。重命名只更新数据库和档案文件，硬盘文件夹需要手动重命名，
     然后执行「刷新数据库」同步路径。

  Q：关闭“启用医院/科室层”后，已有的归档会变吗？
  A：不会。该设置只影响**新的归档操作**，已归档的文件结构保持不变。

  Q：Mac 电脑能用吗？
  A：可以。但需要另外下载 Mac 版本的压缩包（.app），操作方式与 Windows 类似。


                            11. 下载速度慢怎么办？

  如果你在下载 Aurum 时速度很慢，可以尝试以下方法：

  ① 使用浏览器扩展
     安装 GitHub Accelerator 等插件，自动加速下载。

  ② 使用镜像站
     在下载链接前加上以下任意一个前缀：
     - https://ghproxy.com/
     - https://ghproxy.net/
     - https://gitproxy.click/
     例如原链接为 https://github.com/.../Aurum.zip，
     替换为 https://ghproxy.com/https://github.com/.../Aurum.zip 即可。

  ③ 使用加速器（推荐）
     如 Watt Toolkit 等支持网页加速的工具。

  如果以上方法仍无法解决，请尝试其他网络环境或联系技术支持。
